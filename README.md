## User Requirements

1. As a student, I want to see how busy each NYU gym is, so I can decide which gym to go to.

2. As a student, I want to check in when I enter a gym and check out when I leave, so my gym usage is recorded and gym busyness stays accurate.

3. As a guest, I want to register for the an account so I start using the app.

4. As a member, I want to update my bio so that people know how much weight I can bench.

5. As a member, I want to control who can view my profile, so that I feel safe knowing posting on the app.

6. As an admin, I want to update gym details like hours, so that users aren't misled.

7. As an admin, I want to remove posts that break the rule, so that the feed stays respectful and appropriate.

8. As an admin, I want to manage the list of gyms, so that the gym info remains accurate.

9. As an admin, I want to be able to warn or suspend users, so that users do not repeat bad behavior on the app.

10. As a member, I want to delete my account, so that I can leave the platform.
